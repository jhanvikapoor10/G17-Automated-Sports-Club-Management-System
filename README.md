# Sports Club Management System

A Java-based desktop application for managing members, coaches, sports, and sports enrollments through a graphical user interface.

The project was developed to apply **Object-Oriented Programming (OOP)** concepts in a practical application using **Java Swing**.

## Features

* Add and manage sports club members
* Display all registered members
* Search members using their ID
* Remove members
* Add and manage coaches
* Display all registered coaches
* Add and manage sports
* Display available sports
* Enroll members in sports
* Limit sport enrollment based on maximum capacity
* Save and load application data
* Graphical User Interface using Java Swing

## Technologies Used

* **Java**
* **Java Swing**
* **Object-Oriented Programming**
* **Collections Framework**
* **Java Serialization**
* **File Handling**

## OOP Concepts Demonstrated

### Abstraction

The `Person` class is an abstract class that defines common properties and behavior for people in the system.

```text
Person
 ├── Member
 └── Coach
```

The `displayInfo()` method is defined as an abstract method and implemented by subclasses.

### Inheritance

`Member` and `Coach` inherit common attributes such as ID, name, age, and phone number from the `Person` class.

### Encapsulation

Class-specific data such as membership type, coach specialty, salary, and sport information are maintained using private fields and class methods.

### Polymorphism

The `displayInfo()` method is overridden by `Member` and `Coach` to provide class-specific information.

### Composition

`ClubManager` maintains collections of members, coaches, and sports and handles the main management operations.

## Main Classes

| Class                        | Purpose                                                  |
| ---------------------------- | -------------------------------------------------------- |
| `Person`                     | Abstract base class containing common person information |
| `Member`                     | Represents sports club members                           |
| `Coach`                      | Represents coaches and their assigned sports             |
| `Sport`                      | Represents sports and their enrollment capacity          |
| `ClubManager`                | Manages members, coaches, sports, and data persistence   |
| `SportsClubManagementSystem` | Provides the Java Swing graphical interface              |

## Data Management

The application uses Java object serialization to persist member, coach, and sport information.

The following files are generated by the application:

```text
members.dat
coaches.dat
sports.dat
```

Data is saved when the user selects **Save Data** and when the application is closed.

## How to Run

### Prerequisites

* Java Development Kit (JDK)
* Java-compatible IDE such as VS Code, IntelliJ IDEA, or Eclipse

### Run from the Terminal

Clone the repository:

```bash
git clone https://github.com/jhanvikapoor10/Coding-Problems.git
```

Navigate to the project directory and compile the Java file:

```bash
javac SportsClubManagementSystem.java
```

Run the application:

```bash
java SportsClubManagementSystem
```

## Example Workflow

1. Add a member by entering their ID, name, age, phone number, and membership type.
2. Add a coach with their specialty and salary.
3. Add a sport and specify its maximum number of participants.
4. Enroll a member into a sport using the member ID and sport ID.
5. Search, display, or remove member records as required.
6. Save the application data before exiting.

The application also prevents enrollment when a sport has reached its maximum capacity.
